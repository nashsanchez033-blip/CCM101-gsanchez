# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory introduces cloud object storage using MinIO, an S3-compatible object storage server. The activity demonstrates how Docker can be used to quickly deploy a storage service and how object storage can be used to manage user-uploaded files such as images.

## Objectives

- Understand the three main types of cloud storage.
- Compare Block Storage, File Storage, and Object Storage.
- Understand why Object Storage is suitable for user-uploaded images.
- Deploy a MinIO object storage server using Docker.
- Access the MinIO Web Console.
- Create an object storage bucket.
- Upload a sample file to the bucket.
- Document the deployment process and storage concepts.

## Tools Used

- GitHub
- KillerCoda Ubuntu Playground
- Docker
- MinIO
- Linux Terminal
- MinIO Web Console

## Skills Learned

- Understanding cloud storage types.
- Comparing Block, File, and Object Storage.
- Deploying services using Docker.
- Working with Linux command-line commands.
- Configuring environment variables.
- Accessing a web-based cloud storage console.
- Creating and managing object storage buckets.
- Uploading and managing files in object storage.
- Documenting cloud infrastructure.
