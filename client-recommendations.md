# Client Recommendations

## Checkpoint 4 – Cloud Platform Recommendation Challenge

### Client A – Startup Company

**Recommended Platform: AWS**

AWS is recommended because a startup can begin with a small cloud environment and expand its resources as the application grows. AWS provides many managed services, allowing the startup to avoid purchasing physical servers and to pay for the resources it uses. The platform also provides services that can support a mobile application from development to production. Useful services include **Amazon EC2**, **Amazon S3**, and **Amazon RDS**.

**Recommended services:**
- Amazon EC2 – application/backend computing
- Amazon S3 – images, files, and application objects
- Amazon RDS – managed relational database

---

### Client B – University

**Recommended Platform: Microsoft Azure**

Azure is the best fit because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft identity and enterprise technologies, making a hybrid or gradual migration practical. Microsoft Entra ID can help manage identities and access while Azure Virtual Machines can host Windows or Linux workloads. Useful services include **Azure Virtual Machines**, **Microsoft Entra ID**, and **Azure SQL Database**.

**Recommended services:**
- Azure Virtual Machines – migrate server workloads
- Microsoft Entra ID – identity and access management
- Azure SQL Database – managed SQL database workloads

---

### Client C – AI Research Company

**Recommended Platform: Google Cloud**

Google Cloud is recommended because the company focuses on Artificial Intelligence and Machine Learning and requires high-performance computing. Google Cloud provides strong AI, data, compute, and Kubernetes capabilities that can support research and production workloads. Compute Engine can provide scalable computing resources while Google Cloud's AI and data services can support machine learning workflows. Useful services include **Compute Engine**, **Vertex AI**, and **Google Kubernetes Engine (GKE)**.

**Recommended services:**
- Compute Engine – high-performance virtual machines
- Vertex AI – AI and machine learning development
- Google Kubernetes Engine – containerized AI/ML workloads

---

### Client D – Global E-Commerce Company

**Recommended Platform: AWS**

AWS is recommended because a multinational e-commerce company needs high availability, scalability, networking, storage, databases, and global infrastructure. AWS can distribute workloads across Regions and Availability Zones and can automatically adjust capacity as demand changes. This is especially useful during events such as major sales and seasonal traffic spikes. Useful services include **Amazon EC2**, **Elastic Load Balancing**, **Amazon RDS**, and **Amazon S3**.

**Recommended services:**
- Amazon EC2 – scalable application computing
- Elastic Load Balancing – distribute traffic
- Amazon RDS – managed database
- Amazon S3 – object storage

---

# Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Broad services, scalable infrastructure, and flexible cloud deployment options |
| Enterprise Organization | AWS | Large service ecosystem and extensive enterprise capabilities |
| Microsoft Environment | Microsoft Azure | Strong integration with Windows Server, Microsoft 365, and Microsoft identity |
| AI / Machine Learning | Google Cloud | Strong AI, data, and machine learning capabilities |
| Kubernetes Deployment | Google Cloud | GKE provides managed Kubernetes and Google has deep Kubernetes expertise |
| Global Web Application | AWS | Extensive global infrastructure, scalable compute, storage, databases, and networking |

## Final Recommendation

There is no single cloud provider that is automatically best for every organization. AWS is a strong general-purpose choice, Azure is particularly suitable for Microsoft-centered environments, and Google Cloud is especially attractive for AI, data, and Kubernetes workloads. The final decision should always be based on the client's technical requirements, budget, existing systems, skills, compliance requirements, and future growth.
