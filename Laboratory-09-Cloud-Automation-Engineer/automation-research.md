# Automation Research

## Bash Script

A Bash script is a text file containing Linux commands that can be executed automatically in a sequence. The `#!/bin/bash` line, called the shebang, tells the operating system to use the Bash interpreter when executing the script.

## Variables

Variables are used to store information such as file names, directory paths, and other values that a script needs. Using variables like `$BACKUP_DIR` makes scripts easier to update because programmers can change a value in one place instead of editing the same folder path multiple times.

## Cron Job

A Cron job is a scheduled task in Linux that automatically executes a command or script at a specified time. It is important for cloud operations because it allows routine activities such as backups, maintenance, and monitoring to run without requiring manual execution.
