# Reflection

## My Learning Experience

In this laboratory activity, I learned how to work with a Linux environment using the KillerCoda Linux Playground. At first, working with the terminal was unfamiliar to me, but by following the commands and instructions, I became more comfortable using the Linux command line.

I learned how to create and manage a user account, check the current username, identify the working directory, and determine the hostname of the system. I also learned how to gather basic system information and understand the environment where I was working.

## Linux and Cloud Computing

This activity helped me understand the connection between Linux and cloud computing. Many cloud servers and infrastructure systems use Linux, so learning basic Linux commands is an important skill for working with cloud technologies.

I also learned that simple commands such as `whoami`, `pwd`, `hostname`, and other system commands can provide useful information about a computer or server.

## GitHub and Documentation

Another important part of this activity was learning how to use GitHub as a portfolio. I learned how to create folders and Markdown files, organize my laboratory outputs, and document my activities properly.

Using GitHub also showed me how technical work can be stored and organized in a way that can be reviewed and updated in the future.

## Challenges

One challenge I experienced was getting familiar with the Linux terminal and remembering the purpose of different commands. I also needed to make sure that the files and folders in my GitHub repository followed the required structure.

By following the instructions carefully and practicing the commands, I was able to complete the tasks and understand their purpose.

## What I Learned

Overall, this laboratory activity improved my basic knowledge of Linux, cloud computing, and GitHub. I learned that cloud computing is not only about using cloud services but also requires knowledge of operating systems, command-line tools, system information, and proper documentation.

This activity gave me a good foundation for the next laboratory activities in CCM101. I will continue practicing Linux commands and improving my skills in managing cloud-based environments.
