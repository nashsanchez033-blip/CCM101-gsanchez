# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduces the basic concepts and practical skills needed to work in a Linux-based cloud environment. The activities were completed using the KillerCoda Linux Playground and GitHub.

## Objectives

* Access a cloud-based Linux environment.
* Explore and navigate Linux.
* Gather basic system information.
* Create and organize directories and files.
* Create a GitHub repository.
* Document technical activities using Markdown.
* Practice version control using Git and GitHub.

## Activities Performed

1. Accessed the KillerCoda Linux Playground.
2. Created a Linux user with sudo privileges.
3. Logged in to the newly created account.
4. Checked the username, working directory, and hostname.
5. Gathered Linux system information.
6. Created directories and Markdown files.
7. Created a public GitHub repository.
8. Organized laboratory files and screenshots.
9. Documented the completed activities.

## Skills Learned

Through this laboratory, I learned how to access and use a cloud-based Linux environment, manage users, navigate the Linux file system, gather system information, create files and directories, and organize technical documentation.

I also learned the importance of using GitHub to maintain and document a professional technical portfolio.
