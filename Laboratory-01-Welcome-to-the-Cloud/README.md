# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory serves as an introduction to working with a cloud-based Linux environment. The activities were completed using the KillerCoda Linux Playground and GitHub.

The main purpose of this laboratory is to develop basic skills in Linux system navigation, user management, file and directory organization, system information gathering, and technical documentation.

Through this activity, I was able to experience how a cloud-based Linux environment can be accessed and managed using the command line. I also created a GitHub repository to document my work and maintain my laboratory outputs throughout the semester.

## Objectives

Upon completing this laboratory, I was able to:

* Access a cloud-based Linux environment using KillerCoda.
* Explore and navigate the Linux operating system.
* Create and manage a Linux user account.
* Work with Bash and basic Linux commands.
* Gather basic system information.
* Identify the current username, working directory, and hostname.
* Create and organize directories and files.
* Create and manage Markdown documentation.
* Create and organize a public GitHub repository.
* Upload and maintain laboratory screenshots and files.
* Practice version control and documentation using GitHub.

## Command Functions

| Command               | Purpose                                            |
| --------------------- | -------------------------------------------------- |
| `whoami`              | Displays the current username.                     |
| `pwd`                 | Displays the current working directory.            |
| `hostname`            | Displays the hostname of the system.               |
| `cat /etc/os-release` | Displays information about the Linux distribution. |
| `uname -r`            | Displays the Linux kernel version.                 |
| `uname -a`            | Displays detailed system and kernel information.   |
| `lscpu`               | Displays CPU and processor information.            |
| `free -h`             | Displays memory and RAM usage.                     |
| `df -h`               | Displays disk space information.                   |
| `ls`                  | Lists files and directories.                       |
| `cd`                  | Changes the current directory.                     |
| `mkdir`               | Creates a new directory.                           |
| `touch`               | Creates a new empty file.                          |
| `nano`                | Opens the Nano text editor.                        |
| `cat`                 | Displays the contents of a file.                   |
| `sudo`                | Executes commands with elevated privileges.        |
| `su`                  | Switches to another user account.                  |
