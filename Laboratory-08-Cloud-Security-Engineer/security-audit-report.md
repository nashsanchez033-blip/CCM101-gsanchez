# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their tasks. This is important for cloud user accounts because it reduces the risk of unauthorized access and limits the damage if an account is compromised.

## Attack Surface

An attack surface refers to all the possible entry points that attackers could use to access or compromise a system. For a virtual machine, these may include open network ports, running services, exposed applications, and accounts with weak passwords.

## Default Deny Policy

A Default Deny Policy blocks incoming network traffic unless it is specifically allowed by a firewall rule. This approach is safer because unknown and potentially harmful connections are automatically blocked instead of relying on administrators to identify every possible attacker.
