# Microsoft Azure Research


## 1. Brief Overview

Microsoft Azure is Microsoft's public cloud platform for building, deploying, and managing applications and infrastructure. Azure launched in 2010 and provides services for computing, storage, networking, databases, identity, security, analytics, AI, and containers.

Azure is especially useful for organizations that already use Microsoft technologies such as Windows Server, Microsoft 365, Active Directory, SQL Server, and other Microsoft products.

## 2. Global Infrastructure

Azure operates a global network of Microsoft datacenters organized into geographic regions and availability infrastructure. Organizations can choose Azure regions based on factors such as latency, data residency, compliance, and application availability.

Azure also supports availability zones in supported regions to help applications remain available when a datacenter or zone has a problem.

## 3. Cloud Management Console

The **Azure Portal** is the main web-based management interface for Azure. It allows administrators and developers to create and manage virtual machines, storage accounts, databases, networking resources, identities, Kubernetes clusters, and other Azure resources.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide scalable virtual computing resources. They support both Windows and Linux workloads and are useful when organizations need control over the operating system and computing environment.

### Azure Blob Storage

Azure Blob Storage is Microsoft's object storage service. It is designed for large amounts of unstructured data such as documents, images, videos, logs, backups, and other files.

### Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It provides authentication, authorization, access policies, and identity management for users, devices, applications, and resources.

### Azure Kubernetes Service (AKS)

AKS is a managed Kubernetes service for deploying and managing containerized applications. Azure manages important Kubernetes infrastructure so teams can focus more on applications and workloads.

## 5. Three Advantages

1. **Strong Microsoft integration** – Azure works closely with Windows Server, Microsoft 365, Active Directory/Entra ID, SQL Server, and other Microsoft technologies.
2. **Hybrid cloud capabilities** – Azure provides tools for connecting on-premises environments with cloud services.
3. **Enterprise-focused services** – Azure provides extensive identity, security, compliance, database, and management capabilities.

## 6. Typical Enterprise Use Cases

Azure is commonly suitable for:

- Windows Server migration
- Microsoft 365 and identity integration
- Enterprise applications
- Hybrid cloud environments
- SQL Server and database workloads
- Business applications
- Containerized applications
- AI and data analytics
- University and government systems
