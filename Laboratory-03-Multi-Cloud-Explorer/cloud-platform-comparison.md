# Cloud Platform Comparison


## 1. Major Cloud Platform Comparison

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008* |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity Service | AWS IAM | Microsoft Entra ID | Cloud IAM |
| Primary Strength | Broad cloud service ecosystem | Microsoft and enterprise integration | AI, data, and Kubernetes |
| Ideal Organizations | Startups, enterprises, global applications | Microsoft-based enterprises and hybrid environments | AI/data companies and cloud-native organizations |

*Google Cloud's roots include Google App Engine, launched in 2008. The Google Cloud portfolio has evolved significantly since then.

## 2. Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** offers the broadest overall range of cloud services among the three platforms. Its portfolio covers compute, storage, databases, networking, security, analytics, containers, AI/ML, IoT, developer tools, and many specialized workloads. This makes AWS a flexible choice when an organization needs many different cloud capabilities.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** is the strongest choice for organizations that already depend heavily on Microsoft technologies. Azure integrates closely with Windows Server, Microsoft 365, Microsoft Entra ID, SQL Server, and other Microsoft enterprise products. This can make migration and identity management easier for existing Microsoft environments.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud** is a strong choice for Artificial Intelligence and Kubernetes workloads. Google has deep experience in large-scale machine learning and created Kubernetes, while Google Kubernetes Engine provides a managed Kubernetes platform. Google Cloud also provides a broad set of data and AI services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose **AWS** because it provides a very broad collection of services and gives me many options for different types of projects. It is suitable for both small applications and large enterprise systems, so the skills learned from AWS can be useful across many cloud scenarios. I would still choose another provider when the client's requirements clearly favor Azure or Google Cloud.

## 4. Service Notes

### Virtual Machine

All three platforms provide virtual machines for running operating systems and applications. The names differ, but the main purpose is similar: provide scalable virtual computing resources.

### Object Storage

Amazon S3, Azure Blob Storage, and Google Cloud Storage provide object storage for files and unstructured data. They are commonly used for backups, media, application data, logs, and archives.

### Identity Management

AWS IAM, Microsoft Entra ID, and Google Cloud IAM provide identity and access control. Their specific permission models differ, but all help organizations control who can access cloud resources.

### SQL Database

Amazon RDS, Azure SQL Database, and Cloud SQL provide managed database capabilities. They reduce the amount of manual infrastructure and database administration required.

### Kubernetes

Amazon EKS, AKS, and GKE provide managed Kubernetes services. GKE is especially notable because Kubernetes was originally developed at Google.
