# Mission Reflection



The cloud platform that impressed me the most was **AWS** because of its wide range of services and the number of different workloads that can be supported. During the activity, I learned that AWS can support simple applications as well as large enterprise systems through services for computing, storage, databases, networking, security, and containers. However, I also learned that Azure and Google Cloud have important strengths that can make them better choices for specific situations.

AWS, Azure, and GCP have many similarities. All three provide virtual machines, object storage, databases, networking, identity and access management, Kubernetes, monitoring, security, and tools for automation. They also use a similar cloud model where organizations can provision resources when needed and scale their infrastructure according to workload requirements. Even though the service names and interfaces are different, many of the basic cloud concepts are similar.

Business requirements strongly influence cloud platform selection. A company should consider its existing technology, budget, application requirements, security, compliance, performance, location, and expected growth before selecting a provider. For example, Azure is a natural choice for an organization that already depends heavily on Microsoft technologies, while Google Cloud can be a strong choice for AI and Kubernetes workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The correct decision should solve the client's actual problem and provide a practical balance between performance, cost, scalability, security, and management effort.

My GitHub Cloud Computing Portfolio has improved because this laboratory adds a structured multi-cloud investigation. Instead of only documenting individual commands, I was able to compare real cloud services, analyze business scenarios, create recommendations, and explain the reasoning behind technical decisions. This activity helped me understand how cloud computing concepts are applied to real organizations.

## Key Lessons

- Cloud providers have similar basic services but different strengths.
- Business requirements should guide cloud selection.
- AWS is strong for broad cloud capabilities.
- Azure is strong for Microsoft-centered organizations.
- Google Cloud is strong in AI, data, and Kubernetes.
- Technical recommendations should include clear reasons and suitable services.
- Good Markdown documentation makes technical work easier to review and maintain.
