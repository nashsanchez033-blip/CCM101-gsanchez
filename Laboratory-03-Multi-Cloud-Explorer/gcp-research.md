# Google Cloud Platform Research

## 1. Brief Overview

Google Cloud Platform (GCP), now commonly presented as Google Cloud, is Google's public cloud platform. It provides infrastructure, storage, databases, networking, analytics, artificial intelligence, machine learning, containers, and developer services.

Google's cloud platform has roots in services such as App Engine, which launched in 2008. Google Cloud has a strong reputation in data analytics, AI/ML, networking, and Kubernetes.

## 2. Global Infrastructure

Google Cloud provides a global infrastructure organized into regions and zones. Google's current documentation lists **43 global regions and 130 zones**, supporting workloads across multiple geographic locations.

This infrastructure allows organizations to choose locations based on latency, availability, performance, and data residency requirements.

## 3. Cloud Management Console

The **Google Cloud Console** is the browser-based interface used to create and manage Google Cloud resources. Users can manage projects, virtual machines, storage buckets, databases, Kubernetes clusters, IAM permissions, networking, and other services.

Google Cloud also provides the `gcloud` command-line interface and APIs for automation.

## 4. Four Core Services

### Compute Engine

Compute Engine is an infrastructure-as-a-service product that provides virtual machines and bare metal instances. It supports Linux and Windows operating systems and can scale computing resources based on workload requirements.

### Cloud Storage

Cloud Storage is a scalable and managed object storage service. Data is stored as objects inside buckets and can be used for application data, backups, media, archives, and analytics.

### Cloud IAM

Google Cloud Identity and Access Management (IAM) controls who can access Google Cloud resources and what actions they are allowed to perform. IAM uses principals, roles, permissions, and resources to control access.

### Google Kubernetes Engine (GKE)

GKE is Google's managed Kubernetes service for deploying containerized applications. It builds on Google's experience operating large-scale workloads and provides managed Kubernetes capabilities for scalable applications.

## 5. Three Advantages

1. **Strong AI and data capabilities** – Google Cloud has extensive AI, machine learning, analytics, and data services.
2. **Kubernetes expertise** – Google created Kubernetes and provides GKE as a managed Kubernetes platform.
3. **Global networking and infrastructure** – Google Cloud provides a large global network and infrastructure for distributed workloads.

## 6. Typical Enterprise Use Cases

Google Cloud is commonly suitable for:

- Artificial intelligence and machine learning
- Big data and analytics
- Kubernetes and container platforms
- Global web applications
- Data warehouses and data pipelines
- Application modernization
- High-performance computing
- Research and technology companies
